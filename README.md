# 📊 Data Analytics Project

This repository contains a structured collection of SQL scripts, data modeling practices, and exploratory data analysis (EDA) techniques. The queries are designed to solve real-world business problems, perform time-based trend analysis, segment data, and generate actionable insights for Decision Support Systems (DSS).
